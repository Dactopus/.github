# Security policy

Report a vulnerability in any Dactopus repository to security@dactopus.com, not in a public issue or discussion.

Include:

- the repository and the version or commit;
- what an attacker can do, and under what conditions;
- the steps to reproduce it.

## Supported versions

Every repository is below 1.0. A fix is released as a new version of the affected repository; earlier versions are not patched.
